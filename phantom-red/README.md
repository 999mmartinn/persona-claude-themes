# Phantom Red

A Persona-inspired dark look for Claude Code in the desktop and mobile apps. You get jet-black panels with a faint red tint, a blood-red accent, white text, and an animated backdrop: a red and black collage of jagged shards, halftone dots, sweeping slashes and spinning white stars. All the art is original. The theme turns on at session start. Animation stops when the system asks for reduced motion.
